Semantic states

Seven states, the same everywhere. Each has a glyph, a color and a border treatment, so it reads in gray too. Only waiting-user is a filled block. Motion: reading pulses once per event, running shows an indeterminate bar (static stripes with reduced motion), done fades from the writing color once; nothing else moves.

Agents and channel sigils

Identity is a glyph plus a two-letter code plus a cloud (uplink) or local (ground) mark. Codes: CL main Claude session; subagents take the first two letters of their name (EX Explore, PL Plan), with a digit on collision (C2 second Claude session, E2 second Explore); local models take the first two letters of the model family (QW qwen, LL llama).

Buttons, kbd, inputs

The primary button is a 2 px outline on bg-3, never a filled block: the only filled block on screen is the wait. Destructive actions are red outlines and never the default for Enter.

Map pieces

Folders are containers at r-3; files are cells at r-2; agents are pills, so an agent never reads as a file. Links are orthogonal traces with 8 px fillets (the renderer rounds ELK bend points). Writes are solid with a round terminal, reads dashed, attachments neutral. Collapsed folders show a heatmap of reads and writes. The Key legend hides first when the graph does not fit.

Timeline events

One lane per agent, named by its sigil. Events are capsules: dashed for reads, filled for edits, hatched while running; an open capsule runs on to now. Parallel calls never overlap: the lane grows to a second row. An error capsule is labelled with its target (schema.test.ts · 2 failing), never with the tool name. Checkpoints are pills on a dotted line; subagents fork with a rounded elbow.

Cards and telemetry

Telemetry numbers stay at fs-xl so they never outrank the wait. A waiting card carries the request line and its two actions.

Session dock

User messages are bubbles on bg-1; Claude's tool calls collapse into a trace, one line per call, grouped when repeated. The composer shows model, active MCP servers and the automatic checkpoint above the input.

Permission dialog

The only panel that opens by itself. Title in display style on one line, wait clock under it; the full command, the agent's reason, and for writes a diff preview. Approve is the outline primary. Long commands clamp to three lines with an expander; queued requests show a counter.

Status bar

Segments by priority: wait (only when present, the one breathing element), errors, agents, session, tokens, changed files; then VRAM and Docker on the right. Absences are neutral. When space runs out, lower segments fold into ….
