# Glossario

| Termine                  | Significato                                                                                                                                                                                    |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **AgentEvent**           | Evento normalizzato (zod, `packages/event-schema`) che descrive qualsiasi cosa accada: messaggi, tool, file letti/scritti, agenti, MCP, permessi, uso, errori. Tutta la UI si alimenta da qui. |
| **Normalizzatore**       | Adattatore che converte una sorgente (stream-json di Claude, hooks, Ollama, log) in `AgentEvent`.                                                                                              |
| **Fixture**              | Sessione reale registrata e ripulita, usata per design, sviluppo e test senza far girare agenti.                                                                                               |
| **Fixture grezza**       | Registrazione così com'è (`packages/fixtures/raw/`, git-ignored): contiene contenuti di file e percorsi personali. Non si committa e Claude non la legge.                                      |
| **Fixture ripulita**     | Fixture passata da `scripts/fixtures/sanitize.mjs` (`packages/fixtures/sanitized/`): solo chiavi note, contenuti sostituiti da `<redacted>`, percorsi finti. È l'unica che si committa.        |
| **Merge**                | Unione degli eventi di stream e hooks di una sessione (`mergeClaudeSession`): contenuto dallo stream, tempi dagli hooks, un solo evento per fatto.                                             |
| **Merge dal vivo**       | La stessa unione mentre gli eventi arrivano (`LiveClaudeSession`): vince la prima fonte che riporta un fatto, la copia dell'altra si scarta; niente riordino di eventi già mostrati.           |
| **Hooks bridge**         | Script invocato dagli hooks di Claude Code (`packages/hooks-bridge/src/bin.ts`) che inoltra gli eventi all'app via named pipe con il token della sessione (ADR 0009).                          |
| **Run**                  | Un processo `claude -p` di una sessione: uno per ogni messaggio dell'utente, ripreso con `--resume`. Apre con `session.started` e chiude con `session.ended`.                                  |
| **Finto claude**         | `packages/fixtures/bin/fake-claude.mjs`: sostituisce la CLI nei test, riproduce una fixture ripulita ed esegue gli hooks configurati.                                                          |
| **MCP bridge**           | Server MCP dell'app (`delegate_to_local_agent`, `list_local_models`) che permette a Claude di delegare a Ollama.                                                                               |
| **Workspace**            | Cartella di progetto aperta nell'app; confine di tutte le operazioni su file.                                                                                                                  |
| **Vista Live**           | Mappa del progetto + timeline + pannello agenti, sincronizzati sugli eventi.                                                                                                                   |
| **Modello del progetto** | File del workspace, import tra di loro e ruoli (`packages/project-model`, ADR 0012): snapshot appena nota la lista dei file, poi delta numerati per revisione. È la base della mappa.          |
| **Ruolo**                | Cosa fa un file per il framework (pagina, layout, route API, componente, schema, test, config, entry), assegnato da un plugin in base al percorso.                                             |
| **Checkpoint**           | Snapshot del workspace salvato in un ref nascosto prima che un agente scriva; ripristinabile dalla timeline.                                                                                   |
| **Stato derivato**       | Stato della UI ricalcolato dagli eventi: permette il replay in qualunque istante.                                                                                                              |
| **Console Errori**       | Pannello che raccoglie gli errori dell'app e del progetto con lo stack trace leggibile.                                                                                                        |
| **Goal**                 | Condizione verificabile impostata con `/goal` che guida il loop di lavoro di una (sotto)fase.                                                                                                  |
| **Dock**                 | Pannello agganciabile ai bordi della finestra: destro ("Session": chat, input, permessi) e inferiore (Terminal, Logs, Problems).                                                               |
| **Presenza agente**      | Avatar di un agente agganciato sulla mappa al nodo su cui lavora, con un arco diverso per lettura e scrittura.                                                                                 |
| **Segui agente**         | Modalità della mappa in cui la camera segue l'agente selezionato; si interrompe a ogni input sulla mappa (`F` / `Esc`).                                                                        |
| **Vista raw**            | Il JSON originale di un evento, alternativo alla frase leggibile (vista umana); si passa dall'una all'altra con `R`.                                                                           |
| **Test dei 2 secondi**   | Verifica di design: si mostra una schermata per 2 secondi e si chiede una delle 5 domande chiave; supera se la risposta è giusta in 4 casi su 5.                                               |
| **Contratto IPC**        | L'elenco chiuso dei metodi tra renderer e main (`packages/ipc-contract`), ognuno con schema zod di richiesta e risposta. Ogni nuova capacità del renderer è un metodo qui.                     |
| **Envelope IPC**         | La risposta del main a ogni chiamata: `{ ok: true, value }` oppure `{ ok: false, error: { code, message } }`. Nessuna eccezione attraversa l'IPC.                                              |
| **app://**               | Lo schema privilegiato (`app://control-center/`) da cui il main serve il renderer in produzione, al posto di `file://`, con la CSP come header.                                                |
| **Fuses**                | Interruttori scritti nel binario di Electron in fase di build (es. `RunAsNode` off, integrità ASAR on); verificati in `e2e/packaged/fuses.spec.ts`.                                            |
| **Colpevole**            | Il frame di uno stack trace più vicino al guasto fuori dalle dipendenze (5e): è il file che la mappa colora di rosso.                                                                          |
| **Migrazione di evento** | Passo `n → n + 1` di `migrateAgentEvent` che porta un `AgentEvent` salvato alla versione corrente dello schema prima della validazione.                                                        |
