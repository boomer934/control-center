# Problemi noti

| Data       | Problema                                                                                                                                                                              | Workaround                                                                                                                                                             | Stato         |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------- |
| 2026-11-13 | typescript-eslint 8.72 non supporta TypeScript 7 (errore all'avvio di ESLint).                                                                                                        | TypeScript fissato a `^6` (installato 6.0.3); Dependabot ignora `typescript >=7`. Rivalutare quando typescript-eslint supporterà TS 7 (issue typescript-eslint#10940). | aperto        |
| 2026-11-13 | Node 26 non include più corepack, quindi `pnpm` non è nel PATH.                                                                                                                       | `npx pnpm@10.34.9 …` oppure `npm i -g pnpm@10`. In CI si usa `pnpm/action-setup` (legge `packageManager`).                                                             | aperto        |
| 2026-11-13 | La CI usa Node 24 (`.nvmrc`), in locale c'è Node 26.                                                                                                                                  | Nessuno per ora; usare API compatibili con Node ≥ 22 (`engines`).                                                                                                      | da monitorare |
| 2026-11-13 | `gitleaks-action@v2` fallisce al primo push (`<primo-commit>^..` non esiste) e scansiona solo i commit pushati.                                                                       | In CI si usa la CLI gitleaks 8.24.3 su tutta la cronologia (`gitleaks git .`).                                                                                         | risolto       |
| 2026-11-13 | La protezione dei branch non è disponibile per repo private con il piano gratuito di GitHub (HTTP 403).                                                                               | Disciplina: niente push diretti su `main` dopo la Fase 0, solo PR con CI verde. Attivarla quando la repo diventa pubblica.                                             | aperto        |
| 2026-11-13 | Il server MCP Playwright non parte perché manca `chrome.exe`, e il pannello browser non apre `file://` con i parametri.                                                               | Per i mockup HTML: Chromium di `ms-playwright` (chromium-1248) guidato con `playwright-core` dalla cache npx, oppure Edge headless. Script solo nella scratchpad.      | aperto        |
| 2026-11-14 | React Flow 12 con nodi controllati e senza `onNodesChange`: i nodi non vengono mai "misurati", restano `visibility: hidden` e `fitView` non parte (il suo promise non si risolve).    | Passare `width`, `height` e `measured: {width, height}` sui nodi quando le misure sono note (es. da ELK); segnalare la fine del Fit a tempo, non sul promise.          | aperto        |
| 2026-11-14 | gitleaks (`generic-api-key`) segnala chiavi finte nei test anche se costruite a pezzi, quando un pezzo ha alta entropia; scansionando tutta la cronologia, il commit resta segnalato. | Nei test la parte "casuale" è una lettera ripetuta (`'x'.repeat(28)`) o è calcolata a runtime; i commit già fatti vanno in `.gitleaksignore` con il motivo.            | risolto       |
| 2026-11-14 | `@playwright/test` 1.65.1 vuole Chromium 1255, in locale c'è solo il 1248.                                                                                                            | `design/prototipo-live/playwright.config.ts` usa il Chromium più recente in `ms-playwright` (o `PW_CHROMIUM_PATH`). Per allinearsi: `npx playwright install chromium`. | aperto        |
| 2026-11-17 | electron-builder 26 si ferma con `Cannot find module 'tslib'`: `@peculiar/utils` (via `@peculiar/webcrypto`) lo usa senza dichiararlo, e pnpm non lo rende visibile.                  | `packageExtensions` in `pnpm-workspace.yaml` aggiunge `tslib` alle dipendenze di `@peculiar/utils@2`. Toglierlo quando il pacchetto sarà corretto.                     | aperto        |
| 2026-11-17 | electron-builder non trova `electron-builder.config.ts` da solo: senza `--config` impacchetta con i valori di default (cartella `dist/`, nome del pacchetto npm, nessun Fuse).        | Lo script `package:dir` passa `--config electron-builder.config.ts`.                                                                                                   | risolto       |
| 2026-11-17 | In `page.evaluate` di Playwright, `eval` e `new Function` funzionano nonostante la CSP: DevTools li permette durante la valutazione.                                                  | Le prove CSP chiamano `eval` da un `setTimeout`, fuori dalla valutazione, come farebbe uno script della pagina.                                                        | risolto       |
| 2026-11-17 | `electron-vite dev --rendererOnly` avvia comunque Electron, che si prende il lock di istanza singola: un'app lanciata da Playwright si chiude subito.                                 | `e2e/app/dev.spec.ts` avvia solo il dev server Vite (`createServer` con `rendererConfig` esportato da `electron.vite.config.ts`).                                      | risolto       |
| 2026-11-17 | `webContents.getLastWebPreferences()` esiste a runtime ma manca nei tipi di Electron 45; non restituisce `preload`.                                                                   | Nel test un cast locale; il percorso del preload si passa dal test.                                                                                                    | aperto        |
| 2026-11-17 | Le finestre nascoste (`show: false`) non eseguono `requestAnimationFrame`: `waitForFunction` di Playwright non termina.                                                               | `waitForFunction(..., { polling: 100 })`.                                                                                                                              | risolto       |
| 2026-11-17 | Sui runner GitHub Windows non ci sono camera e microfono: `getUserMedia` fallisce con `NotFoundError` prima di chiedere il permesso, e il test del diniego non prova nulla.           | `e2e/launch.ts` avvia Electron con `--use-fake-device-for-media-stream`: con i dispositivi finti la richiesta arriva al gestore dei permessi (`NotAllowedError`).      | risolto       |
