## Costo delle istantanee Git (4b)

La cattura prima del primo turno Claude, l'anteprima e la conferma del ripristino ricostruiscono l'albero completo del working tree con un indice temporaneo. Su repository grandi, anche un ripristino di un solo file può comportare molte letture e scritture di oggetti Git. Alla conferma il main confronta la nuova istantanea con quella vista dall'utente e riusa i percorsi calcolati nell'anteprima. Le verifiche dei file e dei filtri vengono ripetute, perché possono cambiare senza alterare gli alberi Git.
